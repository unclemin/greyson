# 运动训练课助手 · COACHPRO H5

对照抖音视频 [7711016298746163579](https://www.douyin.com/video/7711016298746163579) 实现的移动端优先 H5：AI 体育教案生成工具（表单 → 生成动画 → 教案卡片 → 战术动图）。

## 本地预览

```bash
cd coachpro-h5
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 `http://127.0.0.1:5173`）。建议用手机模式（375×812）查看。

静态预览：

```bash
npm run build
npm run preview
```

## 功能

- 8 大运动项目、需求标签、年龄/人数/时长/场地/器具配置
- 「生成专属训练课」三段式备课进度
- 教案时间轴 + 可展开环节
- 每环节战术 Canvas 动图：分步、拖动、播放/慢速/换球衣
- 单环节「修改」重设文案与强度

## 依据说明

视频可在抖音网页打开并播放。产品为「运动训练课助手 / COACHPRO」，形态接近微信小程序录屏演示。本 H5 复刻其核心流程与深蓝+琥珀视觉，数据为本地演示生成，无需后端。
